# いわての森が育む、いのちの循環
## The Cycle of Life Nurtured by Iwate's Forests

![License](https://img.shields.io/badge/license-MIT-green)
![Three.js](https://img.shields.io/badge/Three.js-0.160.0-orange)

いわての森の木々が辿る「いのちの循環」を、インタラクティブな3Dビジュアライゼーションで表現するプロジェクトです。

An interactive 3D visualization project depicting the "cycle of life" that trees in Iwate's forests follow.

---

## 🌱 Stage 1: 種 — 雪に眠る / Seed — Sleeping in Snow

いわての冬の夜空の下、雪に覆われた大地で、木々の種子が静かに未来を待つ。

Under the winter night sky of Iwate, tree seeds wait quietly for the future, buried in snow-covered earth.

### 特徴 / Features

- **フィボナッチ球面配置**: 黄金角（137.5°）による自然な種子の分布
- **パーティクルシステム**: 数千個の種子と雪の結晶
- **呼吸アニメーション**: 生命の鼓動を表現
- **インタラクティブカメラ**: マウスドラッグで視点変更、ホイールでズーム
- **パラメトリックコントロール**: 種子数、回転速度、発光強度などを調整可能
